# 数和 Kakuro

Kakuro（数和）谜题生成器 + 求解器。纯 Python 标准库，零依赖，一个文件就是全部逻辑。

**玩法**：把 1–9 填进白色格子，要求每一段连续白格里数字**不重复**、
且加起来等于黑格中的**和数线索**（`\` 左边是横向和数，右边是纵向和数）。

## 快速开始

```bash
python -m kakuro                  # 生成一道 6x6 谜题
python -m kakuro --seed 42        # 固定种子（相同种子 → 相同谜题）
python -m kakuro --size 8         # 换大一点的棋盘（4~10）
python -m kakuro --solution       # 生成时同时打印答案
python -m kakuro --save today.txt # 存成文本文件
python -m kakuro --solve today.txt# 求解文件中的谜题
python -m kakuro --hint today.txt # 要一个提示（候选数最少的格子）
python -m kakuro --selftest       # 内置自检
./kakuro --seed 7                 # 也可以直接运行（同目录下）
```

## 小巧思

- **对称黑格**：默认生成 180° 旋转对称的黑格图案，看起来像真正的谜题杂志版面
  （`--style random` 可换成完全随机）。
- **必定有解**：生成时先随机填出一组合法数字，再反推和数线索，所以谜题必有解。
  生成后会顺手数一下解的个数（只数到 2，很快）并如实告诉你是否唯一。
- **提示功能**：`--hint` 会找出当前候选数最少的格子，适合卡住时要一个"最小剧透"。
- **可复现**：任何一道题都可以用 `--seed` 精确复现，方便出题给朋友做。

## 谜题文件格式

`--save` / `--solve` 用的纯文本格式，第一行是边长，之后每行 n 个记号：

```
6
# # # # # #
# r11 . d4 . #
...
```

| 记号    | 含义                 |
| ------- | -------------------- |
| `#`     | 黑格（无线索）       |
| `r16`   | 黑格：横向和数线索   |
| `d7`    | 黑格：纵向和数线索   |
| `r16d7` | 黑格：两个方向都有   |
| `.`     | 白格（空）           |
| `5`     | 白格：预填数字（求解时视为已知） |

## 验证

```bash
python -m py_compile kakuro.py __main__.py   # 编译检查
python -m kakuro --selftest                   # 自检
```

自检内容（全部真实运行）：
1. **已知谜题**：内置一道手工验算过的 4x4 谜题（答案 `1 3 / 4 2`，
   横向和数 4、6，纵向和数 5、5），检查手工答案合法且求解器能解出合法解；
2. **20 个种子**：seed=1..20 生成的 6x6 谜题全部可解，解合法、每段无重复数字；
3. 文本格式存取 roundtrip；
4. 故意写错的和数线索 → 求解器正确返回"无解"；
5. `symmetric` / `random` 两种风格都能生成。

## 局限（诚实版）

- 只适合**小棋盘**（4~10，默认 6）：求解是回溯算法，棋盘再大就会明显变慢。
- **不保证唯一解**：随机图案的约束通常不足以锁定唯一答案，实测 20 个种子里没有一道是唯一解；
  生成器会如实报告"有多解"，不会假装唯一。这是本玩具最诚实的一块短板。
- 生成的谜题难度未经分级，纯粹是"能解"级别的小玩具。
- 需要 Python 3.10+（仅用到标准库：`argparse`、`random`、`itertools`、`re`、`sys`）。
